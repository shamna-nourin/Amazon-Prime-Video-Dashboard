# Amazon Prime Video Dashboard – Power BI

## Project Overview
This project presents an interactive Power BI dashboard to analyze Amazon Prime Video's content library, including movies and TV shows.

The dashboard provides insights into content distribution, genres, ratings, release trends, and geographical distribution.

## Objectives
- Analyze the distribution of Movies and TV Shows.
- Identify the most popular genres.
- Explore content trends over the years.
- Analyze content ratings.
- Understand country-wise content distribution.

## Tools & Technologies
- Power BI Desktop
- Power Query
- DAX
- Data Visualization

## Dataset
Amazon Prime Video titles dataset (`amazon_titles.csv`).

## Dashboard Features
- Total Titles
- Total Movies and TV Shows
- Content by Genre
- Content by Release Year
- Ratings Distribution
- Country-wise Content Analysis
